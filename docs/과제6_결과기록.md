# 과제 6 — 사전학습 모델 비교 결과 기록 (10/21)

## 조건
- 모델: Chronos-Bolt tiny(8.7M) / small(47.7M), Chronos-2(119.5M). `pip install chronos-forecasting`, HuggingFace에서 내려받음. **추가 학습 없음.**
- 입력: 공간별 CO₂ 지난 7일(5분 × 2016칸, 절대값 그대로) → 앞으로 60분(12칸). 분위수 10·50·90% 출력, 점 예측은 50%.
- 평가 시점: 과제 2 eval_points.csv의 시험 구간(10/5~10/18) — 기준선·GRU와 같은 시점.
- 보드: Jetson Orin Nano, JetPack 7.2, 전력 모드 **MAXN_SUPER**(nvpmodel 2), torch 2.14.1+cu132, GPU(cuda), float32, jetson_clocks 미적용.
- 코드: pretrained.py. 결과 파일: pretrained_result.csv, pretrained_interval.csv.

## 정확도 — 시험 CO₂ 60분 MAE (ppm)
| 공간 | 직전값 | GRU(과제 3) | Chronos-2 | Bolt-small | Bolt-tiny |
|---|---|---|---|---|---|
| 사무실 | 43.5 | 36.7 | **34.2** | 35.5 | 38.2 |
| 실습실 | 32.2 | 25.2 | **19.5** | 22.9 | 26.5 |
| 회의실 | 67.1 | 60.4 | **56.6** | 60.1 | 67.2 |
| 직전값 대비 개선 | — | 15.6 / 21.7 / 10.0% | **21.4 / 39.4 / 15.6%** | 18.4 / 28.9 / 10.4% | 12.2 / 17.7 / −0.1% |

- **Chronos-2가 추가 학습 없이 세 공간 모두 직접 학습한 GRU보다 정확함**(실습실은 25.2 → 19.5ppm). 5~30분에서도 같은 순서.
- 추정 이유: 7일 입력으로 하루·주 단위 반복을 직접 보고, 절대값 수준을 매번 입력에서 다시 맞추므로 9/21 이후 수준 변화에 흔들리지 않음. GRU는 지난 2시간만 봄.
- Bolt-tiny는 회의실에서 직전값과 같은 수준 → 너무 작으면 이득이 없음.

## 예측 구간 — 10~90% 구간 적중률 (%, 목표 80%)
| 모델 | 사무실 60분 | 실습실 60분 | 회의실 60분 | 전 공간·전 거리 범위 | 60분 구간 폭(사무실/실습실/회의실 ppm) |
|---|---|---|---|---|---|
| Chronos-2 | 77.6 | 76.2 | 77.6 | 74~82 | **90 / 49 / 145** |
| Bolt-small | 80.0 | 81.2 | 75.6 | 76~82 | 99 / 66 / 161 |
| Bolt-tiny | 80.5 | 76.5 | 74.4 | 74~81 | 106 / 68 / 200 |
- 셋 다 80% 근처(약간 좁게 잡는 편). Chronos-2는 적중률이 2~3%p 낮지만 구간이 가장 좁음 → 실제 쓰기엔 가장 유용한 구간. Bolt-small이 80%에 가장 정확히 맞음.

## 보드 — 1회 추론(시계열 1개, 입력 7일 → 60분, 워밍업 5회 후 50회)
| 모델 | 파라미터 | 평균 | p95 | GPU 최대 메모리 |
|---|---|---|---|---|
| Bolt-tiny | 8.7M | 36.6ms | 38.3ms | 140MB |
| Bolt-small | 47.7M | 49.3ms | 49.8ms | 448MB |
| Chronos-2 | 119.5M | 77.7ms | 78.9ms | 781MB |
- RSS 증가(769 / 459 / 804MB)는 첫 모델에 CUDA 초기화가 포함돼 모델 간 비교로는 부정확 → GPU 최대 메모리로 비교.
- 5분마다 공간 3곳 예측이면 Chronos-2도 한 번에 0.1초 안팎 → 속도는 어느 모델도 문제 아님.

## 채택 의견
- **정확도·구간 기준으로는 Chronos-2를 채택.** 추가 학습 없이 세 공간 모두 GRU를 넘었고(60분 MAE 3~23% 낮음), 구간 적중률 76~78%로 목표에 가까우면서 구간이 가장 좁음. 학습·재학습 관리가 필요 없어 9/21 같은 사용 패턴 변화에도 바로 대응.
- **걸리는 점은 메모리.** Orin Nano 8GB를 로컬 LLM과 같이 써야 하므로 781MB는 부담. LLM 크기 때문에 여유가 1GB 미만이면 **Bolt-small**(448MB, GRU와 비슷하거나 약간 나은 정확도, 구간 적중률 80%에 가장 근접)이 현실적인 대안.
- **GRU(과제 3)는 메모리 수 MB로 가장 가벼움**(파라미터 수만 개) → 메모리가 아주 빠듯하면 GRU, 아니면 Chronos-2. 과제 7(TensorRT FP16 변환)에서 Chronos-2 메모리·시간이 얼마나 줄어드는지 보고 최종 결정 권장.
- Bolt-tiny는 회의실에서 직전값과 같아 채택 이유 없음.
