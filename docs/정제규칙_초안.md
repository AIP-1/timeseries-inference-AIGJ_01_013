## 1. 물리적으로 불가능한 값

**본 것**: 최근 6주 CO₂ 최솟값 380~490ppm, 최댓값 2,582~4,743ppm. 0ppm은 없음. 온도·습도의 범위는 ⚠️ 아직 확인 전.

**결정(예시)**: 아래 범위를 벗어나면 **결측(NaN)으로 바꾼다** (행을 지우지 않음).

| 항목 | 허용 범위 |
|---|---|
| CO₂ | 350 ~ 5,000 ppm |
| 온도 | 0 ~ 45 ℃ |
| 습도 | 0 ~ 100 % |
| 숫자가 아닌 값(문자열) | 전부 결측 |

**이유**
- CO₂는 외기(약 420ppm)보다 많이 낮을 수 없음. 하한 350은 센서 오차를 감안한 여유.
- 상한 5,000은 실내에서 현실적으로 나오기 어려운 수준이면서, 관측된 최대(4,743)는 남기는 값 → 회의실 최대값을 "고장"으로 단정하지 않기 위함.
- 지우지 않고 결측으로 두는 이유: 시간 축이 비지 않아야 결측 처리 규칙(3번)을 일관되게 적용할 수 있고, 몇 개를 걸렀는지 셀 수 있음(진단서에 "제거된 이상값 수" 필요).

**다른 선택지**: 상한을 3,000으로 낮추기(더 보수적) — 단, 실제 고농도 순간까지 지워 예측 성능이 좋아 보이는 착시가 생길 수 있음.

## 2. 튄 값 (범위 안이지만 한 칸만 크게 튀는 값)

**본 것**: ✅ 회의실 최대 4,743ppm(9/17 15:27)은 실제 고농도. 13:37 2,798ppm부터 서서히 올라 17:27 933ppm까지 서서히 내려감 → 튄 값 규칙에 걸리지 않으며 보고서 사례로 좋음(1,000ppm 초과 약 4시간).

**결정(예시)**: **이웃 값과 비교해 혼자 튀면 결측**으로 바꾼다.
- 기준: 직전 값과 직후 값의 평균에서 **CO₂ 300ppm 이상**(온도 3℃, 습도 10%) 벗어나고, 앞뒤 값끼리는 서로 가까우면 튄 값으로 판단.

**이유**: 실내 CO₂는 사람 호흡으로 서서히 오르내림. 1~2분 사이에 300ppm이 튀었다가 바로 돌아오는 건 물리적으로 어렵다 → 통신 오류·잡음.

**다른 선택지**: 이동 중앙값(예: 5칸) 필터로 자동 제거 — 간단하지만 수업 시작 직후의 실제 급상승까지 깎을 수 있음.

> 과제 4(이상 탐지)와의 관계: 여기서 거르는 건 **학습용 정제**. 과제 4 평가에서는 원본(정제 전)으로 탐지기를 돌려야 "튄 값" 고장을 잡는지 볼 수 있음.

## 3. 중복 기록

**본 것**: `081175`(사무실)는 6주 62,322건으로 6주 전체 분 수(약 60,480)보다 많음. 같은 메시지를 게이트웨이 두 대가 받아 두 번 저장된 것으로 추정.

**결정(예시)**: 같은 센서에서 **시각 차이가 5초 이내이고 값이 같은 기록은 하나만** 남긴다.

**12주 건수 확인(10/20)**: 기대 건수보다 많은 센서 4개(`152862` 64,418/60,480, `140101` 13,454/12,096, `081175` 123,587/120,960, `152590`) → 중복 제거 필수. `067999`는 약 11% 부족 → 30분 넘는 끊김 확인 결과 **9일 3.5시간짜리 한 번**이 전부(7/29 11:58 ~ 8/7 15:32, 학습 기간 안). `152590`도 8/7 15:40에 시작 → 8/7 오후에 센서 점검·재설치가 있었던 것으로 추정. 이 9일은 실습실 센서 2개(152862, 140101)로만 계산되므로 보고서에 명시. `089152`는 30분 끊김 3번(기록 1~2개 빠진 정도), `152590`은 8/7 15:40부터 시작(앞 11일 없음), `089152`는 거의 완전.

**이유**: 중복이 남으면 해당 시간대에 가중치가 두 배가 되어 평균이 왜곡되고, 기록 간격 계산도 틀어짐.

**다른 선택지**: 리샘플(5번)에서 평균을 내면 중복 영향이 줄어들긴 함. 다만 "중복을 찾아 처리했다"는 걸 보이려면 명시적으로 거르는 편이 낫다(과제 1 심화와 연결).

## 4. 센서마다 다른 기록 주기 → 분석 간격

**본 것**: CO₂ 센서 간격이 1분(`067999`, `081175`), 2분(`152590`, `152862`), 10분(`140101`, 회의실 `089152`)로 세 종류.

**결정(예시)**: **5분 간격으로 리샘플**(각 5분 칸의 평균). 회의실(10분 센서)은 빈 5분 칸을 **직전 값으로 1칸까지만 채움**.

**이유**
- 과제 3이 "60분 앞까지 **5분 간격**" 예측이라 출력 간격과 맞추는 게 자연스러움.
- 1분 그대로 쓰면 2분·10분 센서는 칸 대부분이 비고, 잡음도 커짐.
- 10분으로 맞추면 회의실은 깔끔하지만 다른 공간의 정보를 버리고, 과제 3의 5분 출력과 안 맞음.
- 회의실 10분 센서 때문에 5분 칸 절반이 비는 문제는 "직전 값 1칸 채움"으로 해결 → 10분 안의 변화는 모른다는 한계를 보고서에 명시.

**다른 선택지**
- 10분 간격: 회의실에 정직하지만 예측 해상도가 낮아짐.
- 1분 간격: 정보량 최대지만 모델 입력이 길어지고 잡음 많음.

> 과제 8 연결: "막 시작된 5분 칸(1~2분치만 있음)을 써도 되나?" — 학습 때 5분 평균을 썼다면 서비스에서도 **꽉 찬 5분 칸만** 쓰는 게 일관됨.

## 5. 결측 (짧은 결측 / 긴 결측)

**본 것**: ⚠️ 센서별로 6주 내내 기록은 있으나, 중간 끊김의 길이 분포는 아직 미확인. 연속 시각 차이가 정상 간격의 3배를 넘는 구간을 세어 볼 것.

**결정(예시)** (5분 리샘플 후 기준)

| 결측 길이 | 처리 |
|---|---|
| 15분 이하 (3칸) | **선형 보간** |
| 15분 초과 ~ 2시간 | 보간하지 않고 **결측 유지**, 해당 구간을 걸치는 학습 샘플은 제외 |
| 2시간 초과 | 결측 유지 + **결측 구간 목록**에 기록(진단서·과제 1 수집 현황에 사용) |

**이유**
- 실내 CO₂·온도는 15분 안에서는 거의 직선으로 변해 보간 오차가 작음.
- 긴 결측을 보간하면 수업 시작 같은 큰 변화가 지워진 "가짜 데이터"로 학습하게 됨.
- **보간은 과거 값만 쓰거나, 시험 기간 경계를 넘지 않게** 할 것 → 미래 값이 과거로 새는 누수 방지.

**다른 선택지**: 짧은 결측도 직전 값 유지(forward fill) — 더 단순하고 누수 위험이 없지만 계단 모양이 생김.

## 6. 한 공간에 센서가 여러 개 (실습실 CO₂ 4개)

**본 것**: 실습실 CO₂ 센서 4개의 바닥값(최솟값)이 380 / 396 / 478 / 489ppm으로 **약 100ppm 차이**. 같은 방이면 빈 시간에 비슷해야 함 → 센서마다 영점이 다름.

**결정(예시)**: 공간을 대표하는 값은 **센서들의 중앙값**. 단, 그 전에 **영점 보정**(7번)을 먼저 적용.

**이유**
- 평균은 한 센서가 튀거나 고장 나면 같이 끌려감. 중앙값은 센서 하나의 이상에 강함.
- 센서 하나만 고르면 그 센서가 멈출 때 공간 전체가 결측이 됨.
- 다만 이상 탐지(과제 4)의 "원인 센서 지목"을 위해 **센서별 원본은 따로 보관**.

**다른 선택지**: 센서마다 따로 예측(공간 대신 센서 단위) — 더 정밀하지만 과제의 "공간별" 질문에 바로 답하기 어려움.

## 7. 센서 간 영점 차이

**본 것**: 6번과 동일. 약 100ppm 차이.

**결정(예시)**: 각 센서의 **학습 기간 새벽(02~05시) CO₂ 하위 5% 값**을 그 센서의 바닥값으로 보고, 바닥값이 **420ppm이 되도록 일정량을 더하거나 뺀다**.

**이유**: 사람이 없는 새벽엔 실내 CO₂가 외기 수준에 가까워야 함(과제 4 심화 힌트와 같은 원리). 학습 기간 값만 써서 계산해야 누수가 없음.

**다른 선택지**: 보정하지 않고 센서 차이를 그대로 둠 — 단순하지만 공간 대표값(중앙값)이 어떤 센서 조합이냐에 따라 흔들림. 보정 여부를 바꿔 기준선 오차를 비교해 보는 것도 좋은 분석 거리.

## 8. 위치 태그 변경

**본 것**: 1년 전체로 보면 `081175`가 `강의실`(5월)과 `사무실`로 찍힌 기록이 있음. 최근 6주에는 위치 변경 없음.

**결정(예시)**: 분석은 **최근 6주(위치 고정 기간)만** 사용. 더 긴 기간을 쓸 경우 센서-위치 매핑은 **가장 최근 태그 기준**으로 하고, 위치가 다른 기간은 제외.

**이유**: 다른 방에서 측정한 값이 섞이면 공간 패턴이 망가짐.

## 9. 학습·검증·시험 분할

**결정(예시)** (6주 기준, 시간순)

| 구분 | 기간 | 길이 |
|---|---|---|
| 학습 | 9/8 (월) ~ 10/5 (일) | 4주 |
| 검증 | 10/6 (월) ~ 10/12 (일) | 1주 |
| 시험 | 10/13 (월) ~ 10/19 (일) | 1주 |
| (제외) | 10/20 당일 | 하루가 덜 참 |

**이유**
- 무작위로 섞으면 1분 뒤 값이 학습에, 1분 전 값이 시험에 들어가 사실상 정답을 보고 푸는 셈 → 성능이 부풀려짐.
- **월요일~일요일 단위**로 끊어 요일 패턴이 각 구간에 고르게 들어가게 함.
- ⚠️ 추석 연휴(2026년 9/24~9/27 전후)가 학습 기간에 있는지 확인. 연휴는 평일인데 빈 방이라 패턴이 다름 → 진단서에 표시하거나 별도 처리.

**함께 지킬 것**
- 정규화(평균·표준편차), 영점 보정값, 튄 값 기준은 **학습 기간 값으로만** 계산.
- 기준선(과제 2)과 모든 모델(과제 3~6)은 **같은 시험 기간, 같은 예측 시점 목록**으로 평가 → 시점 목록을 파일로 저장.

## 10. 고장 구간은 학습에 넣나?

**결정(예시)**
- **학습**: 1·2번에서 걸러진 값은 결측 처리, 장시간 이상(값 고정 등)이 확인된 구간은 제외.
- **평가**: 시험 기간은 **있는 그대로** 평가(고장 구간 포함). 단, 고장 구간 포함/제외 오차를 둘 다 보고.

**이유**: 학습에 고장이 섞이면 모델이 고장을 정상 패턴으로 배움. 반면 평가에서 고장을 빼면 현장에서 실제로 마주칠 상황보다 성적이 좋아 보임.
